Description

A lightweight ontology describing Augmented Physical Objects, Augmented Paintings and Augmented Musical Instruments.

Class Definitions

Augmented Physical Object c

IRI https://luciamarock.github.io/Academics/ontology#AugmentedPhysicalObject
Is Defined By https://luciamarock.github.io/Academics/ontology/classes/augmented-physical-object.html
Description

Physical objects enhanced with embedded computational systems that enable responsive, interactive behavior through human gesture. Unlike traditional objects whose behavior is passive and fixed, augmented physical objects introduce a layer of computational agency that allows them to participate in interaction.
Super Class Of
  • Augmented Painting c

Augmented Painting c

IRI https://luciamarock.github.io/Academics/ontology#AugmentedPainting
Is Defined By https://luciamarock.github.io/Academics/ontology/classes/augmented-painting.html
Description

An ontological category in contemporary art defining an art form that combines traditional painting with embedded technology, sensors, and artificial intelligence to create interactive, responsive, and networked experiences where touch and visual interaction generate evolving sounds and behaviors.
Sub Class Of Augmented Physical Object c

Augmented Musical Instrument c

IRI https://luciamarock.github.io/Academics/ontology#AugmentedMusicalInstrument
Is Defined By https://luciamarock.github.io/Academics/ontology/classes/augmented-musical-instrument.html
Description

Musical instrument extended with sensors, computation, or actuators that modify or enhance its expressive capabilities. These systems expand traditional instrumental interaction by introducing computational mediation between gesture and sound production.
Sub Class Of Augmented Physical Object c
