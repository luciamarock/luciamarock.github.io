workflows_interface module

Interace module for the Workflows

Created on Thu Jan 26 15:47:32 2023

It explicitly uses the module-level entities of utilities.util_functions and SmartControllers.controllersInterface

This interface is called from the main_program and constitutes the operational beginning of the program. In fact, all the tasks performed before this module’s call are stricty focused on the “aquisition of knowledge” of the Recipe Management System program about the real Smart Controllers components by means of the configuration files (resources .xml files).

@author: luciamarock

workflows_interface.init()[source]

Check existence of recipe files and directories

In case not existing, this function generates the default recipes directories. It also checks if, all the controller’s type objects belong to the same substistem and if all the declared instances belong to one and only one controller type.

workflows_interface.start()[source]

Starts the program workflow

It loads the available recipes in the corresponding Controller’s instance and start the User Interface
