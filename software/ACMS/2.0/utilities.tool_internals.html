utilities.tool_internals module

Tool Internals Module

Provides core utility functions, XML/CSV parsing routines, EPICS database parsers, and custom logging handlers.

This module contains the EPICSLogHandler for streaming application logs directly to EPICS Process Variables (PVs) for SCADA integration, alongside helper functions for XML element transformations, CSV parsing, and cavity stabilization math.

class utilities.tool_internals.EPICSLogHandler(maxlen=25, max_str_len=39)[source]

Bases: Handler

Custom logging handler that broadcasts log messages to EPICS Process Variables.

Buffers recent log entries using fixed-length deques and publishes timestamps, log levels, and message chunks to defined EPICS record names via Channel Access.

Parameters:

  • maxlen (int, optional) – Maximum number of recent log records to retain in ring buffers, defaults to 25.

  • max_str_len (int, optional) – Maximum length per string chunk for EPICS waveform/string compatibility, defaults to 39.
