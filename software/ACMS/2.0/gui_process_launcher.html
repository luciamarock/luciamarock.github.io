gui_process_launcher module

Process Launcher Module for the Template Editor Sub-Application.

This module provides process isolation utilities for launching external PySide/PyQt graphical user interfaces from the main ACMS / Recipe Management System runtime.

To maintain system stability, the Template Editor GUI is executed as a decoupled, independent OS process rather than running on the main engine thread. This separation ensures:

  1. Thread/Context Isolation: Qt UI event loops do not interfere with background EPICS Channel Access network sweeps or active workflow threads.

  2. Process Independence: Unexpected crashes or memory issues within the GUI sub-application do not propagate to or compromise the core ACMS daemon processes.

  3. IPC Payload Transmission: Large PV metadata maps generated by editor_interface are serialized to JSON and piped directly into the target GUI process via stdin.

Module Dependencies:

  • gui_launcher: External script entry point invoked by the Python interpreter process.

luciamarock

gui_process_launcher.launch_template_editor(payload)[source]

Launch the Template Editor GUI in an independent process and stream payload via stdin.

Spawns gui_launcher.py in a detached process session (via start_new_session=True) using the current Python interpreter executable. The provided PV metadata payload is serialized into JSON format and written directly to the child process’s standard input stream.

Parameters:

payload (dict) – The sanitized EPICS PV telemetry payload (typically output by editor_interface.scan_archive_network() or editor_interface.san_bob_file()) containing PV names, fields, and operational metadata required by the Template Editor.

Returns:

Handle to the spawned external GUI process. Retaining this handle allows the caller to perform process management tasks such as:

  • Querying process state and lifecycle tracking via proc.pid.

  • Polling process execution health (e.g., checking if active via proc.poll() is None).

  • Programmatically halting or terminating the GUI window using proc.terminate() or proc.kill().

Return type:

subprocess.Popen

Raises:

  • FileNotFoundError – If gui_launcher.py cannot be located in the current module directory.

  • RuntimeError – If the process fails to spawn or if piped payload transmission over stdin encounters an I/O error.
