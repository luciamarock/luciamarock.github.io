utilities.bob_parser module

Phoebus Display (.bob) XML Parser for EPICS PV Discovery.

This utility module provides XML parsing capabilities for Phoebus Display Builder (.bob) HMI screen files used in CS-Studio.

It enables the ACMS Template Editor to automatically discover all Process Variables (PVs) embedded within screen widgets (such as Text Updates, Action Buttons, and Gauges). The extracted PV list is deduplicated, filtered to remove unexpanded Phoebus macros, and sorted before being passed to editor_interface for live Channel Access profiling.

Module Dependencies:

  • xml.etree.ElementTree: Standard library XML parsing engine.

@author: luciamarock

utilities.bob_parser.extract_pvs_from_bob(bob_file_path: str) → list[source]

Parse a CS-Studio Phoebus .bob display file and extract all configured PV names.

Recursively scans the XML tree structure for <pv_name> tags, strips whitespace, filters out unexpanded local macros (e.g., $(PV_NAME)), deduplicates identical widget channels, and returns a sorted list of concrete PV names.

Parameters:

bob_file_path (str or Path) – File path to the target Phoebus .bob XML screen file.

Returns:

A sorted list of unique, valid EPICS Process Variable names extracted from the file. Returns an empty list [] if XML parsing fails or if the file cannot be found.

Return type:

list of str

Error Handling:

Catches xml.etree.ElementTree.ParseError and FileNotFoundError, logging an error message and returning an empty list to prevent application crashes.
