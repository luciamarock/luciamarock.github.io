SmartControllers.factories.types_factories.create_type(root, name)[source]

Function responsible for instatiating the generic class for the controller’s types.

This function is called by controllersinterface.parse_xml_types function.

Starting from xml root node this function assembles the attributes dictionary and the arguments list.

These entities are then passed to the class common_type during instantiation.

Parameters:

  • root – The root node (as read from .xml file)

  • name – The name of the xml file, this name becomes the nme of the Object Class

Returns:

The Controller’s type object class with its name ready to be registered in the controllerinterface.registered_types dictionary
