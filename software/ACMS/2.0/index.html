Automated Control and Management System

ACMS (formerly Recipe Management System) - Control Software Platform

Overview & Background

The Automated Control and Management System (ACMS) is an automated execution engine originally developed for ITER's PBS31 Vacuum System requirements and extended for the Linear IFMIF Prototype Accelerator (LIPAc) campaign operations.

The software orchestrates step-by-step automated recipes, dynamic configuration validation, and complex calibration procedures across smart controller devices and hardware abstraction drivers.

Key Capabilities & Architecture

  • LIPAc Campaign Manager (LCM) Integration: Acts as the backend execution engine for higher-level campaign orchestration and GUI/API monitoring.
  • Automated RF & Vacuum Workflows: Manages multi-chain procedures such as RFQ phase alignment with real-time field fitting, state validation rules, and safety rollbacks.
  • EPICS & Modular Drivers: Integrates with softIoc process variables (PVs), PLCs, RGAs, TPGs, and scopes via modular driver interfaces using pyepics.
  • Flexible Interfaces: Supports both direct Command Line Interface (CLI) execution and a FastAPI-based REST API for remote control.

Repository Structure & Usage

The core software codebase is structured around modular control packages:

├── documentation/   # Sphinx documentation source files and build scripts
├── src/            # Core source code (API, SmartControllers, workflows)
├── tests/          # Unit and integration test suites
└── settings.ini    # Environment and resource configuration settings

Running the Application:

  • Main application: python src/main_program.py settings.ini
  • REST API Server: python -m API.runner
  • Running Tests: pytest tests/
