workflows.rfq_phase_alignment module

Radio Frequency Quadrupole (RFQ) Phase Alignment Workflow Module.

This module implements the RFQPhaseAlignment workflow execution class, which manages the configuration, lifetime loop, and delegate monitoring for RFQ phase alignment tasks.

Key Functionality:

  1. Configuration Ingestion: Reads JSON runtime settings from rfq_phase_alignment_config.json using paths defined in general settings.

  2. Worker Delegation: Instantiates and continuously executes monitoring loops via workers.phase_alignment_worker.PhaseAlignmentWorker.

  3. Workflow Lifecycle Management: Implements standard workflow controls including start (__call__), graceful exit (stop), status reporting (talk), and registration with workflows_interface.

Module Dependencies:

  • workflows_interface: Central workflow registry repository.

  • workers.phase_alignment_worker: Delegate worker class executing phase alignment routines.
