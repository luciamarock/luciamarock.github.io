controllersInterface module

Controllers Interface Module.

Created on Thu Jan 5 11:57:03 2023

Serves as the central registry and parser interface for Smart Controller types and instances. Discovers XML definition files, instantiates controller hardware/software objects via factories, populates the central projectmodel.projectModel.projectmodel tree, and manages validation engines.

Note

This module is imported by main_program immediately following the execution of the _init() setup function.

controllersInterface.create_validators()[source]

Initialize recipe validators declared in configuration settings.

Attempts to instantiate each validator listed in UF.settings["validators"] via validation.validation_engine.create(). Successfully created objects are registered in the validators dictionary.

Returns:

A list of error message strings describing any failed validator instantiations.

Return type:

list of str

Note

Registered validators can subsequently be executed using:

errors = validators[validator_name].validate(
    registered_instances[instance], PVs, os.path.splitext(filename)[0]
)
controllersInterface.parse_xml_instances()[source]

Recursively parse and register Smart Controller instance definitions.

Walks the root directory and all subdirectories within UF.settings["controller_instances_location"] to load instance XML files.

For each unique instance name encountered:

  1. Invokes SmartControllers.factories.instances_factories.create_instance() passing the root node and registered_types.

  2. Registers successfully created instance objects in registered_instances.

  3. Appends the instance node to the global Project tree.

  4. Triggers projectmodel.projectModel.projectmodel.export() upon completion.

See also

  • parse_xml_types()

  • SmartControllers.factories.instances_factories.create_instance()

controllersInterface.parse_xml_types()[source]

Parse and register Smart Controller type definitions from XML.

Scans the directory specified by UF.settings["controller_types_location"] for XML configuration files (ignoring subdirectories). For each file:

  1. Parses the XML tree using lxml.etree.

  2. Invokes SmartControllers.factories.types_factories.create_type() to instantiate the controller type class object.

  3. Registers the returned object into registered_types.

Additionally, this function calls _start_log() to record startup runtime settings and instantiates the global projectmodel object (Project).

See also

  • parse_xml_instances() - Invoked after type parsing completes.

  • SmartControllers.factories.types_factories.create_type()
