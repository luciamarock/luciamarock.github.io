workflows.srf_sentinel module

Superconducting Radio Frequency (SRF) Interlock Sentinel Workflow Module.

This module implements the SRFsentinel continuous interlock monitoring daemon and the associated SentinelRule rule engine.

Key Functionality:

  1. CSV-Driven Interlock Rules: Loads sentinel rules from srf_sentinel.csv to monitor EPICS trigger Process Variables (PVs) against condition statements (including logical operators like AND / OR and NaN readback guards).

  2. Interlock Action Dispatching: Automatically writes specified target values to driven PVs whenever interlock trigger conditions evaluate to True.

  3. Waveform Logging & HMI Metrics: Logs interlock activity messages and timestamps to EPICS waveform arrays (capped at 500 entries) and updates the total active interlock count.

  4. Template Editor Subprocess Execution: Monitors requests via EPICS to launch external GUI template editor processes via gui_process_launcher and editor_interface.

Module Dependencies:

  • workflows_interface: Workflow registration repository.

  • editor_interface: Phoebus display (.bob) sanitization and preparation utilities.

  • gui_process_launcher: Subprocess launcher for external GUI editors.
