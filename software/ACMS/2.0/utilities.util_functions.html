utilities.util_functions module

Utility Functions Module

Provides shared global state containers and helper utilities accessible across all system packages.

This module acts as the centralized storage for global application settings parsed from configuration files (settings.ini), as well as runtime state objects such as UserIntention instances that manage asynchronous command states (e.g., IDLE, PAUSE, ABORT) for background workflow workers.
