utilities.util_functions module

Module Util Functions

Created on Tue Jan 24 15:48:37 2023

This module is expected to contain all the functions that can be shared and used by all the other python modules. It is also the place where important information and software objects are stored in dictionaries. For example the module level settings dictionary contains all the information defined in the settings.ini file plus some other information derived and/or inferred from those ones.

In the same package there is also the validation sub-package since it is also used and shared by many workflows.
