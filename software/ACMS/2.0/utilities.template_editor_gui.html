utilities.template_editor_gui module

Cascading JSON Filter and Export GUI for Template Authoring.

This module provides the core graphical interface component for the ACMS Template Editor sub-application.

It defines the JSONFilterApp window class, which processes incoming EPICS PV telemetry payloads (structured as colon-delimited key names, e.g., "SUBSYSTEM:DEVICE:PARAMETER:FIELD") and presents a cascading set of dynamic dropdown filters (QComboBox widgets).

Operators use this interface to:

  1. Navigate hierarchical PV namespaces by filtering chunk by chunk.

  2. Inspect live telemetry values and metadata field definitions.

  3. Select specific PV entries and append them to an export manifest list.

  4. Save the finalized selection list to disk as a JSON recipe template file.

Module Dependencies:

  • PySide2.QtWidgets: PySide2 (Qt5) layout and widget primitives.

  • PySide2.QtCore: Qt alignment and dimensional constraints.
