API.lcm_executor module

External executor for the LCM automation loop (v0.5.2) — PUSH model, statement DSL.

LCM pushes jobs to the executor; the executor pushes results back to LCM. This executor connects to real EPICS Process Variables (PVs) using pyepics.

  • LISTENS for:

    • POST {this}/run {job_id, sequence, inputs, …} -> runs the job

    • POST {this}/abort {job_id} -> cancels a job

  • PUSHES to LCM:

    • POST {lcm}/api/automation/jobs/{id}/events -> set_field / push_timestep / log / progress / done

Standard-library + pyepics — runs with python3.

Start it and point LCM at it:

python3 tools/lcm_executor.py –port 9100 –lcm http://localhost:8000 LIPAC_EXECUTOR_URL=http://localhost:9100 uvicorn backend.main:app –port 8000

The job’s sequence is the statement DSL (SPEC §4), e.g.:

{ “steps”: [

{ “caput”: { “pv”: “LIPAC:PUMP:A:CMD”, “value”: 1 } }, { “wait”: { “seconds”: 30 } }, { “caget”: { “pv”: “LIPAC:GAUGE:A”, “into”: “gauge_a” } }, { “push_field”: { “code”: “PRES_ACTUAL”, “value”: “${gauge_a}” } }, { “push_timestep”: { “comment”: “after settle” } }, { “done”: { “ok”: true } }

] }

DSL statements mapped to executor → LCM events:

  • caput → log / EPICS write (cached PV connection with timeout)

  • caget → log / EPICS read into a DSL variable

  • wait / wait_until → progress (abort-aware)

  • if / for_each / while → control flow (executor-internal)

  • push_field → set_field (LCM stores it in the job working state)

  • push_timestep → push_timestep (LCM commits a TIME-STEP)

  • log → log

  • done → done (terminal)

log_message(*a)[source]

Log an arbitrary message.

This is used by all other logging functions. Override it if you have specific logging wishes.

The first argument, FORMAT, is a format string for the message to be logged. If the format string contains any % escapes requiring parameters, they should be specified as subsequent arguments (it’s just like printf!).

The client ip and current date/time are prefixed to every message.

Unicode control characters are replaced with escaped hex before writing the output to stderr.
