gui_launcher module

Launcher Entry Point for the Template Editor Sub-Application.

This module serves as the process entry-point script executed when launching the Template Editor GUI sub-application from gui_process_launcher.

It is executed as an isolated child process using PySide2 (Qt5 bindings) to present operators with an interactive interface for editing recipe templates. The module handles data payload ingestion through dual modes:

  1. IPC Stream Mode (Primary): Intercepts --stdin arguments to stream JSON PV metadata directly from the parent process pipe via standard input.

  2. Disk Cache Mode (Fallback/Testing): Reads a local cached JSON file (PVINFO.json) or returns dummy fallback structures for standalone execution and GUI layout debugging.

Module Dependencies:

  • utilities.template_editor_gui: Provides the JSONFilterApp main GUI window class.

  • PySide2.QtWidgets.QApplication: Manages the GUI application control flow and event loop.

gui_launcher.load_json()[source]

Ingest JSON telemetry payload from piped standard input or disk cache.

Determines the input source based on command-line arguments:

  • If --stdin is present in sys.argv, it reads the serialized JSON string directly from sys.stdin.

  • Otherwise, it falls back to reading the local PVINFO.json file from disk.

Returns:

The parsed PV metadata payload dictionary containing PV names, fields, and operational attributes required to initialize the Template Editor widget. Returns an empty dict {} or fallback sample dictionary if ingestion fails.

Return type:

dict
