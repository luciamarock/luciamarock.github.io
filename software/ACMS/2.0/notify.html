notify module

Console Notification and Diagnostics Utility.

Created on Thu Feb 1 15:42:43 2024

Provides standardized, timestamped output logging functions for stdout/stderr during initialization and early runtime phases before full logging facilities are bound.

notify.get_caller_module()[source]

Retrieve the module name of the calling function.

Inspects the current execution call stack to extract the name of the module two frames above this call.

Returns:
