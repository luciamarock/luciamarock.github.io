utilities.db_query module

utilities.db_query.get_list_of_pvs(server: str = 'localhost', database: str = 'lipac_mock', username: str = 'archive', password: str = 'rockoDD1o', use_dashboard: bool = True, only_alive: bool = True) → list[source]

Connects to the local lipac_mock database and retrieves a clean list of PV strings.

  • use_dashboard: If True, pulls from ‘pv_status’. If False, pulls from ‘channel’.

  • only_alive: If True and using dashboard, returns only PVs currently active on the network.
