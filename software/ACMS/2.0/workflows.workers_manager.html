workflows.workers_manager module

Auto-Conditioning Worker Manager Workflow Module.

This module implements the WorkerManager workflow (registered as "AutoConditioningWorkflow" in workflows_interface), which manages the lifecycle, EPICS PV integration, HMI communications, and execution threads for automated conditioning workers.

Key Responsibilities:

  1. Worker Parsing & Factory Instantiation: Parses XML configuration files from the resource directory via workers.factories.factory_interface.WorkerFactory.

  2. EPICS Connection & State Monitoring: Binds EPICS PV control interfaces to individual worker instances, handling enable/abort/reset/stop actions dynamically via callbacks.

  3. Multithreaded Execution: Spawns dedicated daemon threads for parallel worker execution.

  4. HMI Integration: Controls macro propagation and exports worker availability and status waveforms to EPICS for user display.

  5. Configuration Persistency: Synchronizes workspace state on connection setup.

Module Dependencies:

  • workflows_interface: Central registration interface for system workflows.

  • utilities.util_functions: System-wide settings and utility functions.

  • workers.factories.factory_interface: Factory interface creating worker instances from XML.

_enable_callback(pvname=None, value=None, char_value=None, **kw)[source]

EPICS callback handling state transition requests for specific workers.

Evaluates incoming control PV values against worker execution states (running, completed, error, not running, aborted) to trigger abort(), stop(), reset(), or start_worker().

Parameters:

  • pvname (str, optional) – Triggering EPICS PV name.

  • value (int, optional) – Control command value (0 to stop/abort/reset, 1 to start).

  • char_value (str, optional) – String representation of the PV value.

  • **kw – Additional callback keyword arguments.
