SmartControllers.factories.instances_factories.create_instance(root, controller_instance_name, registered_types)[source]

Called by controllersinterface.parse_xml_instances function

This function finds inside the root (xml root node) object all the required information. In particular it first retrieves the “family” of the curren instance, using the family it retrieves the Type software object from the parameter registered_types and from there it collects the instance_attributes (these attributes are the one the user defines in the xml file of the Controller’s Types); it means that those attributes are considered “mandatory” and must be found in the instance configuration file.

Thus it then proceeds to find al the required and expected attributes inside the root element. It collects all the information in the attributes dictionary.

Parameters:

  • root – The xml root node

  • controller_instance_name – The name of the Controller’s Instance (same as the nema of the xml configuration file)

  • registered_types – module level dictionary controllersInterface.registered_types

Returns:

The instanciated software object representing the physical component
