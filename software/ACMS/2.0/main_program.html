main_program module

Main Program Entry Point.

Created on Wed Nov 2 15:14:01 2022

Serves as the primary entry point for the Recipe Management System (RMS). Initializes system configurations, sets up logging handlers, populates global runtime settings, and boots system controller interfaces and workflows.

Usage:

$ python main_program.py path/to/settings.ini

main_program._init()[source]

Initialize system-wide configurations and setup application environment.

Reads and validates the settings.ini file passed as a command-line argument. Initializes project directories, configures workspace paths, establishes file/EPICS logging streams, and populates the global runtime dictionary utilities.util_functions.settings.

Raises:

SystemExit – If command-line arguments are missing, the target ini file does not exist, or required configuration sections (project, workspace, logging, resources, validation) are malformed or missing.

See also

  • controllersInterface - Invoked following initialization to parse XML configurations.

  • utilities.util_functions - Holds the global settings dictionary updated here.
