main_program._init()[source]

Initialization function

Uses the global variable “config” which is the Configuration Parser

It first checks if the “settings.ini” file that you passed as an argument exists.

If that’s the case it starts reading the .ini sections and building-up the settings dictionary.

Finally it stores the finalized settings dictionary into utilities.util_functions.settings from wich it can be accessed by all the other modules of the program.

After this _init function the main program invokes the controllersInterface module.
