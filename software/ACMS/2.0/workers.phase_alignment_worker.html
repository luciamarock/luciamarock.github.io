workers.phase_alignment_worker module

Phase Alignment Worker Module

Provides the PhaseAlignmentWorker execution engine to perform real-time multi-chain RF phase alignment for RFQ cavities.

The worker orchestrates EPICS Channel Access PV connections, chain hardware isolation, oscilloscope sampling via utilities.scopelib, Levenberg-Marquardt field fitting via utilities.rfq_calib_utils, and automated safety validation checks.

Orchestrates multi-chain RF phase alignment, hardware isolation, and safety checks.

Communicates with EPICS Process Variables (PVs) to manage master and slave amplifier states, monitor runtime user commands (RUN, PAUSE, ABORT), and perform least-squares optimization of cavity phase setpoints.

execute_full_alignment()[source]

Execute complete multi-chain RF phase alignment scan sequence.

Iterates over all configured slave chains, isolates each target chain, acquires phase scan voltage samples using the oscilloscope interface, and performs Levenberg-Marquardt least-squares curve fitting.

Evaluates safety constraints prior to setting new phase angles:

  • Forward Wave Unbalance Limit: Must not exceed max_allowed_unbalance_percent.

  • Minimum Cavity Voltage: Peak voltage must equal or exceed min_expected_cavity_voltage.

If an error or safety violation occurs, the current slave chain is restored to its original initial phase setpoint and all amplifiers are re-enabled.

Raises:

ValueError – If forward wave unbalance exceeds safety limit or cavity peak voltage drops below minimum.
